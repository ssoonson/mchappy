# 행복 마을

마인크래프트 에듀케이션을 활용한 사회정서학습 자료 소개 사이트입니다. 기본 월드 배치도, 수업 PPT의 다섯 차시, 3·7차시 활동지 미리보기를 제공합니다.

## 외부 자료 링크 연결

`links.js`에 공개 공유 주소를 입력합니다.

- `world`에는 행복 마을 기본 월드의 공유 주소
- `slides`에는 수업 PPT의 공유 주소
- `worksheets`에는 3·7차시 활동지 PDF의 공유 주소
- 세 자료를 같은 폴더에서 제공한다면 `sharedFolder`에 폴더 주소 하나를 입력

파일별 링크가 있으면 그 링크가 우선합니다. 빈 항목은 공유 폴더 주소로 연결되며, 둘 다 비어 있으면 외부 열기 버튼이 표시되지 않습니다. 미리보기는 사이트에 포함되어 있습니다.

## GitHub Pages에 올리기

1. 압축을 풀고 `index.html`, `styles.css`, `links.js`, `app.js`, `assets/`, `.nojekyll`을 저장소 루트에 올립니다.
2. 저장소에서 **Settings → Pages → Build and deployment**를 엽니다.
3. **Deploy from a branch**를 선택하고, 소스 브랜치(예: `main`)와 **`/ (root)`**를 지정한 후 저장합니다.
4. Pages 설정에 표시되는 사이트 주소에서 미리보기와 자료 링크를 확인합니다.

별도 설치나 빌드가 필요하지 않습니다. 배치도와 활동지 미리보기에는 원자료에 기반한 이미지를 사용했습니다. 외부 자료의 공유 권한은 원본 서비스에서 설정합니다.

- [GitHub Pages 소스 설정 공식 안내](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
- [토스페이스 공식 저장소와 사용 안내](https://github.com/toss/tossface)

이 페이지에는 토스팀에서 제공한 토스페이스가 적용되어 있습니다.
